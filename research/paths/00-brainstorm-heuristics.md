# 头脑风暴生成启发式（H1–H6）

> **适用范围：整个 Macha** —— 论文/理论、Core、Layer、工程与协作，全部适用；不限于某一条路径或某个模块。
> 本文件**只保留六条生成启发式**。原先同批产生的取材清单、候选清单、筛选标准与推荐，已按决策作废。
> 用法：对同一个对象依次跑 H1–H6，每条产出一行候选。

| # | 启发式 | 操作定义 |
|---|---|---|
| **H1** | **否定承重假设** | 先写出当前方案的承重假设（一两句），逐条取反，每个反命题作为一个候选 |
| **H2** | **换原语** | 找出方案的最小单位（时间 / 数据 / 决策 / 关系 / 世界），换掉它，其余保持 |
| **H3** | **反转载荷方向** | 把"输入 → 计算 → 输出"的方向反过来（先产出后解释 / 先写后读 / 先承诺后推理 …） |
| **H4** | **减法** | 删掉方案中的一个组件，检查目标是否仍然成立；若成立，被删的那个是冗余 |
| **H5** | **换失败面** | 写出方案当前优化掉的那个失败，改以另一个失败作为首要优化目标 |
| **H6** | **时间尺度分离** | 把"同一循环处理所有事"的部分，拆成若干时间尺度上各自独立的循环，层间只传最少量 |
