## 1. 主张

> **内驱力是五原语中 `independence` 的唯一机制候选**：其他四根（continuity / contingency /
> expression / reciprocity）都能靠"更会回应"改善，只有 independence 不能。
> 因此它的位置很窄，但**那个位置目前没有替代品**。

## 1.5 在 SepMay 图里的位置（生态位）

**它不新增盒子。** 它在已有图里横跨三个位置：

```text
接收域                          运算域                        输出域
外部信息源 ┐                                              ┌ Ive Chunk → Thread
           ├──▶ 算子集合 ──②内驱力算子──▶ ────────────────┤ Ive Chunk → Thread
内部信息源 ┘         ▲                                    └
   ▲ ①drive 电平      │                                         │
   └──────── ③回流：用结果更新 drive ←───────────────────────────┘
```

| 位置 | 内驱力在这里是什么 |
|---|---|
| **① 内部信息源** | 一类**持久状态**（drive 电平）——不是事实件，属回流三路的**"权重"那一路** |
| **② 运算域 · 算子** | 把近期历史（设定点偏离 / 学习进度 / 选项增长）折成 drive 变化，与设定点比较 |
| **③ 回流** | Chunk 关闭后的结果**更新 drive**——这就是环能自己转起来的原因 |

> **结构性角色（一句话）**：**外部信息源决定"世界让我开 Chunk"；内驱力决定"我自己开 Chunk"。**
> 它是这个环里**唯一的内部发起源**：外生入口是世界（玩家/环境），内生入口只有它。

**没有内驱力，这张图在无外部输入时静止；有内驱力，环自己转。**

**边界**：它**不在接收域**（那里只有事实与已提交状态），**更不在 Layer**（Layer 只报事实、执行动作、拒绝）
——只有一格算子 + 一格状态。

## 2. 唯一研究问题（可判定）

> **在一个没有玩家、没有外部任务的世界里，什么信号能让 NPC 持续产生"非重复、可满足、不漂移"的目标？**

- 若答案存在 → independence 有了机制，`Other` 原型有了实现路径。
- 若不存在（所有信号都退化为重复或随机）→ 内驱力应整条放弃，independence 只能靠**预置的 ambient 行为**（世界本身很活时够用）。

**判据**：三种失败形态各自可观测——① 锁死（同一动作重复）② 随机（行为与 drive 无关）③ 漂移（长期行为模式无理由改变）。

## 3. 四个竞争设计（同一条路径内的竞争假设，不是一个问题的四种表述）

> 它们**只换"drive 从什么信号来"这一项**，agent 接口、环境、指标全部相同 → 实验能**判别**。

| # | 设计 | drive 信号 | 预测（相对其它三个） | 失败信号 |
|---|---|---|---|---|
| **P2-A** | **稳态设定点**（Homeostatic，报告路径③） | 若干慢变量的**偏离量**（能量/好奇饱和度/连接度） | 最容易被人类读懂、最稳；在**空世界**里也持续 | 行为锁死（总选同一个 drive）；drive 不动 |
| **P2-B** | **学习进度**（Learning Progress，报告①） | **预测误差的变化率**（不是误差本身——避免"噪音电视"） | 课程式推进，coverage/step 优于随机与新奇 | LP 排序 ≈ 随机；或瞬间饱和 |
| **P2-C** | **赋能/affordance 寻求**（Empowerment，报告①） | 可达成动作集合（选项数）的增长 | 产生**改造环境**的行为 | 估计与真实选项增长无关；或过度保守（报告已知偏差） |
| **P2-D** | **连接/关系驱动**（Relatedness，报告④） | **关系状态 R** 的偏离（想接触/想回避） | 产生"找玩家"行为，但**有界不粘人** | 无视玩家（independence 过强）或粘人/纠缠（contingency 被挤掉） |

**共同的控制组（必须）**：`P2-0` = 无 drive（纯随机/纯反应）。任何设计若不能显著优于 P2-0，视为失败。

## 4. 判别实验矩阵

**同一环境 × 同一 agent 接口 × 只换 drive 模块**，每条跑 N 次不同种子（复现性要求）。

| 实验 | 环境 | 变量 | 观测 |
|---|---|---|---|
| E-1 | 空世界（无玩家、静态） | P2-0 / A / B / C | 自主目标数、行为熵、coverage、drive 循环 |
| E-2 | 有 affordance 的世界（可改造） | P2-0 / C | 选项增长、环境改动次数 |
| E-3 | 有脚本玩家（进/出） | P2-0 / D | 找玩家率（>0 且有界）、**退场后不坍塌**、回来后能引用 |
| E-4 | 长期（10× 时长） | 全部 | 行为漂移率、复现性（同种子） |
| E-5 | 换环境（sim → Minecraft，M7 之后） | 胜出者 | **泛化（F6）**：结论是否只在我们的 sim 上成立 |

## 5. 指标（8 条，全部可从 transcript 算出）

1. 自主目标数 / 时间（非重复） 2. 行为熵 3. coverage / 选项增长 4. drive 被满足后是否切换行为
5. 无干预持续运行时长 6. **行为漂移率** 7. **复现性**（同种子同结果） 8. 找玩家率（有界）

> 6、7 沿用报告 §9.1 里"行为漂移 / 复现性"两个指标；8 是报告里**完全没有**的关系侧补白（我们的差异化）。

## 7. 边界规则（沿用上轮四条硬约束，不得违反）

1. **drive 必须落在 Core 侧内部信息源**（路径一的"权重"那一路），**不许写在提示里**；
2. **自生成目标必须经 IC 的 Chunk 准入**，不许另开目标通道；
3. **内驱力不得改变事实**：只动权重/陈述件，事实件不变；
4. **每个 drive 必须有衰减 + 上限 + 可观测 + 可关闭**。

另：**Layer（`:simulator`）不得含任何 drive 逻辑**——它只报事实、执行动作、拒绝。

## 11. 反对意见（留给未来）

- 若四个设计都跑不赢 P2-0 → `independence` 应改由**预置 ambient 行为**实现（世界本身很活时够用），
  本路径**整条放弃**；
- 若结论只在我们的 sim 上成立 → 属 **F6 泛化失败**，必须记 `research/failures/`，不得当作结论；
- 若 drive 变成了"忙个不停" → 那是**反效果**：independence 挤掉 contingency，等于换了一种失败。
