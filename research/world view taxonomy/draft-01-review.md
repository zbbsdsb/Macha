## 0. 总体判定

**结论：方向正确，第一性地基可用；但作为一套"分类法"，它目前尚未成立，需要一次结构性修正。**

Draft 01 做对了最关键的一件事：**拒绝按题材分类，转向按结构分类**。这个转向是对的，也是 Macha 真正需要的。

但它目前有两类问题：

1. **内部问题**：六要素与六轴都不同程度地"不正交"——部分维度是派生量或被放错了层级。
2. **外部问题**：这套分类法目前**预测不了我们真正关心的因变量**（接入难度、幻觉风险、一致性维护成本）。一个解释不了代价的分类法，是漂亮的，但不是可用的。

## 1. 必须保留的三个核心洞察（不要动）

在批评之前，先锁定 Draft 01 里真正有价值、且应该进 Macha 理论地基的东西：

| # | 洞察 | 为什么它是对的 |
|---|------|----------------|
| 1 | **"世界观的核心不是写了什么，而是什么能够导致什么"** | 这一句把 World 从"文本资产"重新定义为"动力系统"。它是整个 Macha 存在的前提。 |
| 2 | **Lore ≠ State + Rule** | 这是 anti-hallucination 的理论基础。AI 需要的不是叙述性 Lore，而是可判定的 State 与可执行的 Rule。 |
| 3 | **World Permeability** | 全篇最有价值的原创概念。它把一个模糊的"能不能接 AI"问题，变成了一个可度量的结构问题。 |

这三条建议原样保留，并作为后续所有讨论的前提。

## 2. 诊断

### 诊断 1：W = (E, S, R, H, O, C) 中至少三个要素不是独立的

六要素看起来齐整，但拆开看，它们的层级并不一致：

| 要素 | 问题 |
|------|------|
| **H（History）** | 历史不是世界的独立组成，它就是状态的时间序列：`H = trace(S_0 … S_t)`。把它与 S 并列，等于把"电影"和"胶片"并列。 |
| **C（Causality）** | 因果不是独立层，它就是 Rules 沿时间轴的展开。一旦有了 `T`（转移函数），因果就被 `T` 完全决定了。C 与 R 高度重叠。 |
| **O（Observability）** | **层级错误。** 可观测性不是"世界的属性"，而是 **Agent 与世界的接口属性**。同一个物理世界，可以全知访问，也可以部分可观测——这取决于你在哪个 Agent 上，而不取决于世界本身。把它塞进 World 六元组，等于把"观察者的眼睛"算成了"被观察对象的一部分"。 |

**修正建议：分层，而不是并列。**

```
本体层 (Ontology)      : E (Entities), S (State), R (Rules / T)
派生层 (Derived)       : H = trace(S), C = R 沿时间的展开
认知接口层 (Interface) : O —— 独立出来，属于 Agent-World 边界
```

这样六要素一个都不丢，但层级清晰了：**世界只需要 (E, S, R)，其余都是派生或接口。**

> 好处：这直接对应到工程——`E/S/R` 是存储与规则引擎的事，`O` 是 perception 层的事，`H` 是 memory/日志的事。分层即模块划分。

---

### 诊断 2：六轴不正交，且缺两根工程上最关键的轴

**重叠问题：**

- **Axis 1（Determinism）↔ Axis 3（Causality）**：Scripted 世界几乎必然 Strongly Closed；Evolving Causality 几乎必然要求 Emergent。两根轴在实践中难以独立打分。
  - *解法*：重新切分——
    - **Determinism = 事件序列（S）的自由度**（作者锁的是结果，还是状态空间）
    - **Causality = 规则集（R）本身是否可变**（`R_{t+1} ≠ R_t` 是否允许）
    - 这样一个是"状态自由度"，一个是"规则自由度"，正交了。
- **Axis 2（Openness）↔ Axis 3**：Generative World（新实体类别）通常必然要求规则可变。需要明确 Openness 只谈 **E 的增长**，不谈 R。
- **Axis 4（Knowledge）**：严格说属于 Agent 侧而非 World 侧。但它有一个可以辩护的世界侧版本：**"世界对真相的承诺程度"**——有些世界结构上就提供唯一可访问的真相（数值系统），有些则根本不提供（宗教、历史解释）。建议保留，但改名为 **"Truth Commitment"** 以免层级混淆。

**缺失轴 A：Granularity / Resolution（粒度）**

这是我认为**最严重的遗漏**。

对照两个世界：《十字军之王 3》与《Dwarf Fortress》。两者都是高 Emergence、高 Agency 的世界。但：

- CK3 只模拟到"领主之间的好感度数值、头衔、军队规模"；
- DF 模拟到"每个矮人的每根手指、每种酒的成分、每次被蜘蛛咬后的中毒反应"。

**这直接决定 AI NPC 的感知带宽和行动空间。** 一个"高 Emergence 但低分辨率"的世界（CK3）与一个"低 Emergence 但高分辨率"的世界（物理沙盒），对 Framework 的要求完全不同——前者需要长程规划与社会推理，后者需要海量状态压缩。

粒度应包含两维：**状态空间的细致程度** × **时间步长（tick）**。

**缺失轴 B：Verifiability / Decidability（可判定性）**

这一根直接决定工程难度，而 Draft 01 完全没有。

问题很具体：AI NPC 说"我杀了国王"——**这个世界能判定这句话成不成立吗？**

- 有强数值系统的世界：能判定（血量归零 + 事件日志），幻觉会被系统直接否决。
- 纯叙事世界：不能判定，只能靠 LLM 自洽或与另一个 LLM 辩论。

**这一根轴，是 Macha 反幻觉机制难度的直接预测器。** 没有它，这套分类法回答不了"接这个世界要付多大代价"。

### 诊断 3：Permeability 是原创亮点，但被错误地标量化了

Draft 01 把 Permeability 画成 0% → 100% 的单一标度。这在实践中会误导，因为**渗透不是一扇门，而是一组不同的门**。

典型反例：几乎所有商业 RPG 都是"对话层 100% 渗透 + 规则层 0% 渗透"。用单一百分比描述它，得到的是 25% 还是 50%？都不对——它是**在两个不同层上分别处于两个极端**。

**修正建议：向量化。**

```
Permeability = (w_S, w_R, w_H, w_E)

w_S : Agent 能否写入 State（改变世界状态）
w_R : Agent 能否写入 Rules（改变规则）
w_H : Agent 能否写入 History（改变已发生的事 / 写入新历史）
w_E : Agent 能否写入 Entities（创造新实体 / 新实体类别）
```

这四个布尔/分级权限，直接就是 `grant_agency()` 的参数位。

> 好处二：Permeability 从此不再是"对世界的某种模糊评价"，而是**Agent 与世界之间的写权限矩阵**。它把分类法和 API 设计真正接上了。

### 诊断 4：整个体系缺一个角色——Player 的建模

Draft 01 的图里出现了 Player，但**没有给它任何结构性定义**。这是一个真实的工程缺口。

关键约束被漏掉了：

> **NPC agency 的天花板 = f(player agency, 叙事主权)**

在绝大多数商业世界里，NPC 的自由度不是被"世界规则"限制的，而是**被"不能抢玩家戏份"这个元规则限制的**。一个 NPC 可以自主经商、结党、造反——只要它不抢走玩家的主线节点。

这不是世界的属性，也不是 Agent 的属性，而是**第三方的分配决策**：叙事主权（Narrative Sovereignty）在 Player / NPC / System 之间如何分配。

**建议**：把它作为一个独立维度或一组约束加进来，否则 Macha 会在"技术上完全可行、体验上完全不可接受"的地方翻车。

---

### 诊断 5：解释力检验——这套分类法目前预测不了"接入成本"

这是最需要团队正视的一点。

我们建分类法不是为了满足智识趣味，而是为了回答一个工程问题：

> **"这个世界，能不能接 AI NPC？接了要付多大代价？风险在哪？"**

对照 Draft 01 的六轴，逐一看它们与"接入成本"的关系：

| 轴 | 能预测接入成本吗？ |
|----|------------------|
| Determinism | 部分——越 Scripted，AI 越无事可做，但也越安全 |
| Openness | 部分——越开放，幻觉空间越大 |
| Causality | 弱 |
| Knowledge | 弱 |
| Canon | 弱 |
| Agency | 部分 |

**没有一根轴直接、强相关地映射到"工程代价"。**

补上 **Verifiability（可判定性）** 之后，情况会明显改善——因为它直接决定：能否用确定性校验拦住幻觉，还是只能靠概率性自洽。

**建议**：明确写出"分类法的因变量是什么"。如果因变量是接入难度，那么每一根轴都应该能被问一句："它如何影响这个难度？"答不上来的轴，要么重新定义，要么删掉。

---

### 诊断 6：从坐标系到 API 的推论跳跃过大

第八节从"六维坐标系"直接跳到 8 个 API（`register_world()` … `commit_transition()`）。中间缺了一整段论证。

问题不是这 8 个 API 错——它们看起来方向对——而是：

- **最小可用集是什么？** 如果只能留 3 个，留哪 3 个？
- 这 8 个 API 里，哪几个是"世界侧"的，哪几个是"Agent 侧"的，哪几个是"仲裁侧"的？

**建议**：先定义最小接口（我猜是 `define_rules()` + `register_agent()` + `validate_action()`），验证它能跑通一个最小世界，再谈扩展。否则这份文档会从"理论地基"滑向"过早的架构设计"。

## 3. 修正提案（供讨论，非定稿）

### 3.1 世界本体：三层而非六元并列

```
本体层 (Ontology)      : E, S, R
派生层 (Derived)       : H = trace(S), C = R 的时间展开
认知接口层 (Interface) : O
```

### 3.2 修订后的轴（7 根）

| 轴 | 低端 | 高端 | 与接入成本的关系 |
|----|------|------|-----------------|
| **Determinism** | Scripted | Emergent | 高 Emergence = 高设计自由度，也高失控风险 |
| **Openness (E)** | Closed | Generative | 越开放，幻觉空间越大 |
| **Rule Mutability** | Fixed R | Evolving R | 规则可变 = 需要规则版本治理 |
| **Truth Commitment** | Omniscient | Epistemically fragmented | 越碎片化，推理/欺骗/情报系统越有价值 |
| **Canon Hardness** | Hard | Living | Living Canon = 需要历史版本治理 |
| **Agency** | Reactive | Autonomous society | 越高，越需要多智能体协调与冲突仲裁 |
| **Granularity** *(新)* | Coarse | Fine | 决定感知带宽与状态压缩策略 |
| **Verifiability** *(新)* | Decidable | Undecidable | **直接决定反幻觉机制难度** |

（Verifiability 或可并入 Granularity，但两者独立——一个高精度世界仍可能不可判定，如果它没有校验器。）

### 3.3 Permeability 向量化

```
Permeability = (w_S, w_R, w_H, w_E)
```

## 4. 给团队的开放问题

1. **因变量是什么？** 这套分类法最终要预测"接入难度"、"叙事质量上限"，还是"技术可行性"？先定因变量，再定轴。
2. **H 和 C 应该降为派生层吗？**（诊断 1）
3. **O 应该移出 World 定义吗？**（诊断 1）——这会改变 Macha 的模块划分。
4. **Granularity 和 Verifiability 是否应入轴？**（诊断 2）
5. **Permeability 是向量还是标量？**（诊断 3）——我倾向向量。
6. **叙事主权（Player vs NPC agency 分配）要不要建模？**（诊断 4）
7. **下一步是先深化坐标系，还是先做一个最小 World Runtime 原型来验证？**——我个人倾向后者：坐标系会越辩越细，但一个能跑的最小世界会立刻暴露哪些轴是必要的。

## 5. 回到 Draft 01 提出的那个锋利问题

> "把可渗透性从 0% 推到 100%，中间会出现哪些新的世界形态？"

基于诊断 3，我认为这个问题应该被**重构**为二维展开：

```
            w_R (规则可写)
              ↑
              │  AI 立法者        AI 世界构建者
              │  (改规则)         (改规则+造实体)
              │
              │  AI 公民          AI 创造者
              │  (改状态)         (造实体)
              └────────────────────────→ w_E (实体可写)
```

而 `w_H`（历史可写）是第三个方向——它决定 AI 能否改写"过去"，这是最有争议也最危险的一维。

**我怀疑真正的"新世界形态"不是沿一条线出现的，而是这个三维权限空间里的不同区域。** 这可能才是 Macha 真正的理论核心 —— 比"AI NPC Framework 架构图"更核心。
