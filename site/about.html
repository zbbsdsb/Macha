Macha · 辅助

关于与参与

Macha 是一个研究工程仓库，不是一个商业产品，也不是一个完整的游戏。它定义的是骨架，任何人都可以在其上实现自己的大脑与环境。

类型 · 辅助 许可 · MIT License 来源 · 仓库说明与招募材料
一 · 项目性质

开源、引擎无关、模型无关

Macha 的目标不是造一个「能聊天」的 NPC，而是构建一个 LLM 驱动的 NPC 框架，让长期记忆、可信反思、动态规划与多智能体协作成为标准的一部分，而不是每个项目的私货。它由两个可分离的系统加一层契约组成：一个与环境无关的 Macha Core，以及每个外部世界各自实现的一份 Environment Integration Layer。Minecraft 是第一个具体 Layer 测试用例，不是框架的身份。

项目以 MIT License 开源，版权归 CeaserZhao 所有。仓库当前的排序是 Layer 先、Core 后：第一个可验证的里程碑是 Layer 协议 + Stub Core + Minecraft Layer，而不是认知核心——真认知核心属于 Phase 3，尚未构建。这一点被刻意写在明面上。

诚实的当前状态

认知核心：尚未构建（Phase 3）。SEPMAY 路径：PENDING，已冻结。内驱力路径：ACTIVE，实验轨道。公开这些状态不是为了显得谦虚，而是为了筛掉不合适的期待。

二 · 参与方式

三条路径

如果你在做 NPC 架构、游戏 AI 研究、Minecraft / inZOI 智能体或 modding，我们欢迎交流与协作。参与不只有一种形态。

论文与材料

读论文草稿与仓库文档，用 issue 或 PR 提出问题、异议与反例。文档里的开放问题都是真实待答的，而不是修辞。

实验

复现算子沙盒，或参与 Layer 验证：勘测一个环境、写一份 Layer、提交回放 transcript。负面结果同样欢迎——失败必须入库。
