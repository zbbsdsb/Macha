这一页将包含什么

Macha 的公开实验只有一个目的：让抽象在真实世界里被证伪一次。这一页记录赛道、判据与结果——包括没跑通的那些。结构已定，正文未定。

  1. 赛道不是项目身份 —— Minecraft 是第一个 Concrete Layer Test Case，inZOI 是第二条观察与设计映射赛道；两者都不是「Macha for Minecraft」或「Macha for inZOI」。
  2. 唯一因变量 —— 给定 Core，接入一个世界所需的一切是否全部落在 Layer 一侧。判断标准是边界是否守住，不是 NPC 在游戏里看起来多聪明。
  3. 五条退出判据 V1–V5 —— V1 Core 代码改动量 = 0（本计划的核心）、V2 环境泄漏、V3 认知上移、V4 可替换性、V5 可独立实现。
  4. 三个前置门与最小交付物 —— G0 环境勘测 / G1 协议 v0 冻结 / G2 Stub Core，以及 M1–M9 九项最小 Layer 交付物。
  5. 里程碑与顺序 —— P0 勘测到 P6 移交 Phase 3；Layer 先、Core 后，V1/V4 先在 Stub Core 上成立，Phase 3 用真 Core 重测。
  6. 已跑过的实验 —— 算子沙盒里的 E-S1（continuity 档，2026-10-07，证据等级 E1），以及它的三条 trace 与 ablation。
  7. 公开与可回放 —— 能力清单、回放 transcript、协议问题清单（每一条「为了接通而想改 Core」的冲动都转成一个协议问题记录下来）；负面结果按 F1–F7 归档。
