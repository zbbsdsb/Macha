这一页将包含什么

结构已定，正文未定。下面的大纲是这一页将要展开的章节，每一章都对应仓库里已经存在的材料；正文会在材料定稿后逐节补齐，而不是先写一段概述再回头改。

  1. 两个系统，一个契约 —— 为什么 Macha 不是一个「带游戏支持的系统」，而是两个可分离的系统加一层协议。
  2. Macha Core 是什么 —— 认知循环、模块职责，以及 2026-09-13 对 src/macha/ 的代码审计结论：核心目前是非认知骨架。
  3. Layer 是什么，不是什么 —— 五条必须属性（双向、单环境、诚实、非认知、独立版本）与四条「不是」。
  4. Layer 协议 —— 五类交换：Observation、Event、Action、Action Result、Capability；以及有争议的第六类 State。
  5. 能力清单与可验证性 —— 声明必须来自探测而不是文档；环境无法表达的动作是正常结果，不是错误。
  6. 最小 Layer 与证明条件 —— M1–M9 交付物、三条证明条件、五条退出判据（V1–V5）。
  7. 反模式 —— 六条会悄悄破坏边界的写法，例如 Core 里出现 if game == "minecraft"。
