这一页将包含什么

SEPMAY 已经回答了「信息存在哪里、活多久、以什么粒度写回」，但没有回答「信息进入系统之后可以被做哪些变换」。这一页是那后半个问题的容器。结构已定，正文未定。

  1. 算子是什么 —— 对信息、Thread 或内部状态施加的一次状态变换：State → Operator → State'，核心问题只有「什么发生了变化」。
  2. 三个必须分开的东西 —— External Information（获得了什么）/ Operator（做了什么）/ Internal State（留下了什么）。由此：Memory Store ≠ Operator Space，Tool Calling ≠ Operator Space。
  3. 最小候选基 —— SELECT / RELATE / TRANSFORM / TEST / COMMIT。这是实验假设，不是分类学：不完备、不声称正交、不排除合并或删除。
  4. 作用对象 —— Information / Thread / State 三层，风险依次递增；一旦涉及 State 就直接连上回流写入权。
  5. 状态语义 —— (X, Internal State, Context) → (X', Internal State')。同一个信息在不同内部状态下做同一个操作，可能得到不同结果。
  6. 如何发现算子空间 —— 三个可跑的实验：E-OS1 标注、E-OS2 组合、E-OS3 状态依赖，以及它们各自的失败形态。
  7. 明确不做 —— 一上来定义二十到五十个算子、把 Reflection / Planning / Reasoning 全叫算子、宣布候选基已经完备。
