Macha · 路径一 · SepMay / IVY 生命周期

SEPMAY 路径

NPC 不该为每一次交互都付整条思维链的代价。

状态 · PENDING（已冻结） 外部评分 · 6.5 / 10 层级 · Core 侧（Phase 3） 收敛 · 2026-09-14
一 · 它解决什么问题

为交互赋予生死

交互被组织进有明确生死的生命周期单元，单元内只在局部上下文里计算，关闭时把结果回流到内部信息源。这样一次交互的代价不再等于整条思维链，而是等于它所在单元的预算。

它把系统划成三层，互不越界。约束是单向的：IC 不决定 NPC 怎么想，但 IC 决定 NPC 能想起什么粒度。因此 IC 只有一条设计义务——不得产生「人不可能有的记忆形态」，例如精确复述三小时前的每一句话，或同一件事存在两套互不知情的记忆。

这条义务把「忘，还是记得太具体」从人格问题降级为数据层约束：测试里出现「记得比人多」或「两套记忆互不知道」，一律算 IC 的 bug，与人格设定无关。

二 · 结构

接收域 · 运算域 · 输出域

接收域                    运算域                     输出域
外部信息源 ┐                                    ┌ Ive Chunk → Ive Thread …
           ├→ 算子集合（一切即插件）→ ───────────┤ Ive Chunk → Ive Thread …
内部信息源 ┘                                    └
     ↑                                              │
     └──────────── 数据回流 ←────────────────────────┘

图的读法有三条。第一，回流不改写外部信息源：被改写的只有「他自己」——事实 append-only，内部状态才可提交更新。第二，内部信息源同时是运算域的输入与回流的目标，因此图上有一个环，这个环必须由 IC 的关闭时点（两阶段提交）做闸门，否则运算域会读到自己未提交的中间态。第三，因此接收域的职责是准入，不是接收。

准入，不是接收

接收域决定什么进入这个 agent 的世界模型、以什么粒度、带什么不确定性（window / truncated / verifiability）。它的产品是「有门的事实」，而不是世界的拷贝。接收域不做赋义——赋义属于运算域的算子。

三 · 层级定位

三层，互不越界

三层各自管什么
层管什么
认知层NPC 怎么想、记什么、有无人格、一致不一致
数据组织层 = IC
（Chunk / Thread）		谁和谁归一组、这组数据活多久、以什么粒度被写出与读入
环境层（Layer）Minecraft 里发生了什么

重要性、情绪、关系亲密度与戏剧价值被明确排除在特性集之外，因为它们需要判断，属于认知层的输出。认知层可以贴标签，但调度侧不得自行计算。

五 · 当前状态

这条路径此刻是冻结的

冻结原因写得很直接：连续数轮都在定义概念，没有任何一项被现实检验。处置是——IC 现在冻结，不投入实现；当前唯一在推进的是 Layer（Phase 1–2）。等 Layer 的八步闭环跑通、协议有了实测，再回头用现实检验 IC，而不是继续在纸上分辨。

解冻条件（三条满足任一）

  • 条件一Layer 的八步闭环完成。
  • 条件二出现一个真实场景，逼着回答「寿命类怎么分档」。
  • 条件三愿意为 IC 写一个最小可证伪版本。
诚实状态

这一页的价值不在于把 SEPMAY 讲成成果，而在于公开它此刻的位置。招募材料里那句「认知核心：尚未构建 —— Phase 3」被直接印在页面上，事后复盘认为它是全文档最有效的一处设计：对的人是加分，错的人是筛掉。SEPMAY 页沿用同一种做法。

六 · 未定决策

11 条未定项，明确不阻塞任何实现

三条硬规矩：未定项不阻塞任何实现；未定项若被临时猜一个，必须显式标注为临时假设并写明作废条件；每条都写了「何时必须回答」，到点仍未回答，则该路径不得解冻。

七 · 与 Layer 的关系

它不改协议，也不阻塞实现

Layer ↔ 接收域 ↔ plugin 的正式映射已经定了：Layer 是外部信息源的生产者，不在接收域内，也读写不了内部信息源；意图流（ActionCall）不经过接收域，只有事实回流经过；plugin 不是 Layer，它是该 Layer 在一个环境内的部署载体，因此不持跨会话状态、重启不丢记忆、不含任何「需要历史」的逻辑。

仍然只是预留、不实现也不冻结的，是 IC 预期会让协议多出来的三样东西：action_result(pending) 语义、observation 的节奏与压力事实、action 的 deadline / budget。它们登记在协议 v0 的预留说明里，等试跑实测后再定。

反对意见，留给未来的自己

若 IC 最终只是「分批写内存」，那它就是普通的内存分层，不值得叫一条路径。真正的风险不在 Chunk 怎么划，而在回流那一步：它是人格漂移与假记忆的唯一产地。若回流三路分离挡不住它，IC 应被整条放弃，而不是继续加机制。
