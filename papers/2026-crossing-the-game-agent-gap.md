# 跨越游戏Agent的那个鸿沟

## 总论

从有效状态机到行为树，再到LLM的横空出世，游戏里的NPC已经进化了几十年
回到那个最根本的问题：我们到底需要怎么样的游戏Agent?下面我们不从技术实现的角度去分析，
而是从玩家的角度：我们渴望那个游戏里的agent是什么样的？

## 场域叠加

### 2.1 被长期混用的两种视角

在讨论游戏智能体时，一个最常见的做法是先把环境信息按来源进行分类：自然信息与社会信息。自然环境释放的信息进入一个运算域，社会环境释放的信息进入另一个运算域，随后系统为不同来源分配相应权重，形成智能体对环境的整体判断。这一传统可以追溯到感知系统、效用函数与行为树的输入设计之中。

为了便于后文讨论，我们将这类做法统称为**源域分解（Source-Domain Decomposition）**。

设游戏世界在某一时刻发生事件 \(e \in E\)，其信息源标记为：

\[
s(e)\in\{N,S,M\}
\]

其中 \(N\) 表示自然源，\(S\) 表示社会源，\(M\) 表示混合源。源域分解将事件 \(e\) 的信息量写为：

\[
I(e)=\alpha(e)I_S(e)+\beta(e)I_N(e)
\]

\(\alpha\) 与 \(\beta\) 是来源权重。该模型的隐含假设有三点：信息在进入主体之前就已经被拆解；其权重不依赖接收者是谁；信息的意义主要由来源决定。

必须承认，源域分解在工程上是有效的。它让智能体能够区分“天在下雨”与“有人背叛了我”这两类完全不同的信息，并据此调节行为。然而，本文要讨论的场域叠加并不是这一含义。源域分解处理的是信息的**发出端**，而场域叠加处理的是信息的**接收端**。前者回答“信息从哪里来”，后者回答“信息在谁的认知中成为意义”。一个向外发，一个向内收；一个以发出者为中心，一个以接收者为中心。

### 2.2 认知场域

为了正式讨论接收端，我们引入**认知场域（Cognitive Field）**。

**定义 1（认知场域）**：对任意主体 \(a\)，其认知场域 \(F_a\) 是一个四元组：

\[
F_a=(W_a,\Phi_a,T_a,V_a)
\]

其中：

- \(W_a\) 是观察窗口，决定哪些事件能够进入主体 \(a\) 的认知；
- \(\Phi_a\) 是解释函数，将事件映射为主体的认知意义；
- \(T_a\) 是时间与记忆层，决定事件如何与主体的过去相叠加；
- \(V_a\) 是价值与人格层，决定事件在主体世界中的评价。

主体对事件的处理因此不是简单的加权，而是：

\[
m_a(e)=\Phi_a(e;T_a,V_a)
\]

\(m_a(e)\) 是事件 \(e\) 在主体 \(a\) 的场域中被重构之后的意义。

认知场域的关键性质是**主体相关性**。同一条信息进入不同场域，会产生不同意义；甚至进入同一个人的不同场域，也会产生不同意义。

### 2.3 场域叠加

现实世界中，每个人都拥有自己的视角，而这些视角并不彼此替代，而是同时存在、相互叠加。玩家在游戏中的状态正是如此。

**定义 2（场域叠加）**：玩家在游戏中的认知场域由至少两个场叠加而成：

\[
F_{player}=F_{in}\oplus F_{meta}
\]

- \(F_{in}\) 是游戏内场：玩家作为游戏世界中的一个行动者，处理角色、任务、战斗、经济等游戏内信息。
- \(F_{meta}\) 是游戏外场：玩家作为知道系统规则、玩法目标、社交语境与自身现实经验的外部观察者。

游戏内的智能体则通常只拥有：

\[
F_{npc}\subseteq F_{in}
\]

这里需要强调，\(\oplus\) 不是标量相加，而是两个参考系对同一事件的同时作用。同一事件会在两个场中分别获得意义，并且这两种意义可能互相冲突。玩家不会先进行“自然/社会”分类，再把结果相加；玩家会同时以“游戏内角色”和“游戏外玩家”两种身份理解眼前发生的一切。

例如，玩家连续三次在夜间进入同一家酒馆，只和同一位 NPC 交谈。在游戏内场中，这个事件被解释为“我在与这个人建立关系”；在游戏外场中，它同时被解释为“我在刷好感度，这可能关系任务奖励”。两种解释并不互相抵消，而是叠合在玩家对 NPC 的每一次观察之中。

### 2.4 视角鸿沟

由此，玩家与 NPC 之间的差异可以被形式化为：

\[
G=F_{player}\setminus F_{npc}
\]

由于 NPC 通常仅活动于游戏内场，这一鸿沟近似为：

\[
G\approx F_{meta}
\]

这意味着，游戏 Agent 与玩家之间的根本差距，不是信息量之差，而是**信息处理场之差**。NPC 不是“知道得更少”，而是缺少一整层接收并解释信息的方式。因此，鸿沟不能靠增加传感器、扩大感知范围或提高自然/社会信息权重来填补。

据此，我们得到本文的第一个核心判断：

**判断 1**：源域分解是接收者无关的，场域叠加是接收者相关的。前者对任何主体给出相同的输入表达，后者则因主体的观察窗口、解释函数、记忆与人格不同而产生不同意义。

**判断 2**：源域分解是场域叠加的退化形式。只有当所有主体共享同一认知场时，信息意义才可能被一组全局权重所替代。而游戏 NPC 的失败，恰恰源于系统试图用统一的源域模型去处理本应分散在不同认知场中的意义。

**判断 3**：游戏 Agent 的真实性鸿沟，不是信息缺失，而是场域缺失。玩家在一个叠加场中理解 NPC，NPC 却只在一个单一场中处理信息。

### 2.5 从场域叠加到“真实”

上述分析为“真实”提供了一个新的标准。一个 NPC 之所以显得虚假，不是因为它的感知数据太少、语言模型不够大，或者行为树层级太浅，而是因为玩家始终在 \(F_{in}\oplus F_{meta}\) 中解释它，而它只对 \(F_{in}\) 负责。任何来自游戏外场的解释，例如“这是脚本”“这里只有三句台词”“它在等我完成任务”，都会直接击穿 NPC 的真实感。

因此，跨越鸿沟的正确方向不是让 NPC 获得玩家的游戏外视角，而是让 NPC 拥有一个**边界清楚、内部一致、可被玩家在其叠加场中理解**的认知场。这正是下一节所要讨论的“真实的必要”。
