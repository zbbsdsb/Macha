# Papers

本目录用于存放 Macha 团队自己撰写与维护的论文、技术报告和思想草案。

## 命名约定

- 文件名使用英文 slug，便于跨平台与 Git 管理。
- 中文标题放在文件头部 YAML metadata 中。
- 同一篇论文的修订版本在同一文件中更新，不创建 `v2` 副本。

## 文件状态说明

| 状态 | 含义 |
|---|---|
| `draft` | 正在起草，内容尚未完整 |
| `review` | 已完成初稿，等待内部评审 |
| `submitted` | 已投稿 |
| `published` | 已发表 |

## 提交规则

1. 每篇论文单独一个 `.md` 文件；若需要图片，放在 `papers/assets/<论文slug>/` 下。
2. 初稿先写清楚：问题、核心概念、论证链、结论；不要过早美化措辞。
3. 每次更新在文件末尾追加“修订记录”。
